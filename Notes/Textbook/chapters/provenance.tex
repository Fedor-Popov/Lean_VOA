\chapter{Provenance: the library state documented by this edition}\label{ch:provenance}

file of the library is assigned to one chapter of the book. The table lists, for each chapter of this
edition, the number of Lean files of the released library assigned to it (11622 files in all); chapters
without files of their own are omitted. The chapters in preparation are not part of this edition. The 38 files of the released library assigned to them are not counted.
